For an internship report that includes **Agile Scrum**, the best approach is to separate the **internship** (company, context, work) from the **project management** (Scrum, sprints, deliverables). This is a structure commonly accepted by engineering schools.

## Front Matter

1. Cover Page
   - University logo
   - Company logo
   - Internship title
   - Project title
   - Student name
   - Supervisor (company)
   - Academic supervisor
   - Academic year

2. Acknowledgements

3. Abstract (French and/or English depending on your university)

4. Table of Contents

5. List of Figures

6. List of Tables

7. List of Acronyms

---

# Headers & Footers

### Header

- Left: Chapter title
- Right: Section title

Example:

```
Chapter 4 — Sprint 1                     4.2 Sprint Backlog
```

---

### Footer

```
-----------------------------------
Internship Report 2026        Page X
```

or

```
Company Name | Internship Report | Page X
```

Avoid putting your name in the footer unless your university template requires it.

---

# Page Numbering

- Roman numerals (i, ii, iii...) for front matter.
- Arabic numbering (1, 2, 3...) starting from Chapter 1.

---

# Chapter Opening Pages

Each chapter should begin on a new page with:

- Large chapter number
- Chapter title
- One short introductory paragraph (3–5 lines)

Example:

```
Chapter 4

Sprint 2 — Expert Profile Management

This chapter presents the realization of the second sprint.
It details the sprint objective, backlog, design, implementation,
and validation of the developed functionalities.
```

---

# Figures

Every figure should have:

```
Figure 4.3 — Class Diagram of Expert Management
```

Never leave a figure without an explanation afterward. A short paragraph explaining what the reader should observe is sufficient.

---

# Tables

Always include:

- Table number
- Caption
- Reference in the text

Example:

```
Table 4.2 — Sprint 2 Backlog
```

---

## Overall hierarchy

```
Cover Page
Acknowledgements
Abstract
Contents
Figures
Tables
Acronyms

Chapter 1 - Introduction
Chapter 2 - Company & Project Context
Chapter 3 - Agile Scrum Methodology
Chapter 4 - Sprint 1
Chapter 5 - Sprint 2
Chapter 6 - Sprint 3
Chapter 7 - Sprint 4 (optional)
General Conclusion
Bibliography
Appendices
```

This layout is conventional, reads professionally, and works well for software engineering internship reports while naturally accommodating Scrum deliverables.
